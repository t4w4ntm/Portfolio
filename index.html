About Me

Thesis Project

ระบบต้นแบบเมืองจำลองดิจิทัลเชิงปฏิสัมพันธ์เพื่อสนับสนุนการตัดสินใจด้านสิ่งแวดล้อม (คลองสาน · ธนบุรี · บางรัก)

โครงงานนี้พัฒนา Urban Digital Twin บน Unity ที่เชื่อมข้อมูลจริงแบบเรียลไทม์ เพื่อสำรวจและสื่อสารผลกระทบของนโยบายสิ่งแวดล้อมต่อพื้นที่เมืองกรุงเทพฯ โดยเน้น UHI (เกาะความร้อนในเมือง) และ PM2.5. แพลตฟอร์มทำงานเสมือน Virtual Sandbox ให้ทดลอง “เพิ่มพื้นที่สีเขียว / เปลี่ยนวัสดุพื้นผิว / มาตรการลดร้อน” แล้วดูการเปลี่ยนแปลงของอุณหภูมิและคุณภาพอากาศอย่างเข้าใจง่าย

  • Objective: สร้างต้นแบบ Digital Twin ที่เชื่อมข้อมูลเซ็นเซอร์และ API เพื่อนำไปใช้ประกอบการตัดสินใจเชิงนโยบาย
  • Scope: พื้นที่นำร่อง 3 เขต (คลองสาน · ธนบุรี · บางรัก)
  • Simulation: Heatmap อุณหภูมิ, การแสดงผล PM2.5, ทดลอง “What-if” เช่น เพิ่มต้นไม้/เปลี่ยนวัสดุ
  • Outcome: เครื่องมือสื่อสารข้อมูลซับซ้อนให้ผู้มีส่วนได้ส่วนเสียเข้าใจเร็วขึ้น และเปิดทางสู่การมีส่วนร่วมของประชาชน
